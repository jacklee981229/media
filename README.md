# media

Photos and videos for [Jack's Space](https://jacklee981229.github.io/), served by GitHub Pages at
`https://jacklee981229.github.io/media/`. They live here, not in the site's repo, so the site's history stays small.

- **One folder per trip**, for the travel posts, written by [Media Studio](https://github.com/jacklee981229/media-studio)
  when a trip is published: each photo's largest size on top (`<id>.webp`), its two smaller sizes in `smaller/`. Not
  edited by hand.
- **`projects/showcase.mp4`**: the video on the [Projects page](https://jacklee981229.github.io/projects/), made in its
  own project (showcase-video) and copied here after each render.
- **`music/`**: the songs of the site's music player, from Pixabay (their licence; each song's page is linked in the
  player), AAC at 96 kbps. The list the player reads, with each song's title, artist and waveform, is in the site's repo.
